Project Overview

This project focused on building a liquidity risk monitoring analytics model to improve early risk detection for institutional trades. By analyzing historical trade settlement patterns and portfolio exposure data, the reporting pipelines were completely automated, reducing manual effort by 34%.

Tools & Technologies Used

SQL & Snowflake

Developed complex SQL queries within the Snowflake data warehouse to aggregate trade lifecycle data, calculating settlement delays and counterparty exposure metrics.

Python (Pandas/NumPy)

Applied statistical trend analysis to calculate Z-scores and flag abnormal settlement delays, identifying liquidity stress indicators to improve risk detection by 17%.

Power BI

Designed interactive executive dashboards to track portfolio liquidity utilization, settlement efficiency trends, and exposure risk indicators for real-time operational monitoring.
